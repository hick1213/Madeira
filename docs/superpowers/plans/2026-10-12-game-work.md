# Game session background work implementation plan

> **For agentic workers:** Execute the bounded tasks below in the existing shared workspace. Preserve unrelated changes and report source hashes and actual runtime checks; do not commit or publish.

**Goal:** Pause Madeira downloads and nonessential library work automatically during every game session, then safely resume it.

**Architecture:** A main-actor GameSessionWork coordinator tracks preparation plus real library/native state. Existing Steam and Epic transfer state machines remain the owners of their download queues. Scanners and catalogue work consult the same coordinator.

**Tech Stack:** Swift, Combine, UIKit; existing native Wine bridge; Python host test orchestration.

**Spec:** docs/superpowers/specs/2026-10-12-game-work-design.md

## Constraints

- Preserve Steam's connection ownership, Cloud quit-upload exception and user manual pauses.

- Ordinary fixtures/reports on external IPAInspection; exact APFS temporary fixtures only where required, finally-cleaned.
- Code and Python changes require independent review. Real device target is Fang Dong's M5 iPad.

## Review focus

- Legacy Wine launches without Library.current must still release after native exit.
- Detach completion while Wine/server remains running must not resume background work.
- Interrupted/stale Epic catalogue requests cannot publish into a new account or replace a newer refresh.
- Manual pauses and account changes while game mode is active retain the user's current intent.
- Save-operation acquisition and game startup are mutually exclusive on the main actor.
